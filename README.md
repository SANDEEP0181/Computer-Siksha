# Computer Siksha

A free bilingual (Hindi + English) computer-learning platform for beginners.

## Platforms
- Responsive website / installable PWA
- Native Android app (Kotlin + Jetpack Compose)
- Shared bilingual course catalogue
- Offline-first learning roadmap

## Phase 1
This repository starts with the web/PWA learning shell and a 12-module syllabus catalogue. Android starter code and richer lesson content are being added in subsequent commits.

## Run locally
From the `web` directory:
```bash
python -m http.server 8000
```
Open http://localhost:8000.

## Course modules
1. Introduction to Computers
2. Computer Hardware
3. Input, Output and Storage Devices
4. Operating System and Windows Basics
5. Office Productivity
6. Internet and Networking
7. Software and Coding Basics
8. Cyber Security and Online Safety
9. Keyboard Shortcuts and Typing
10. Computer Data and Storage Units
11. Basic Troubleshooting
12. Modern Technology

## Principles
- Free learning access
- Hindi and English content
- Beginner-friendly explanations
- Original or properly licensed educational images
- No account or personal data required for the initial release

## Status
Phase 1 starter. Full lessons, image assets, quizzes, progress persistence, accessibility checks and release testing remain in development.
