# Computer Siksha — 12 Module Syllabus

Each module will be expanded into bilingual lessons with definitions, explanations, diagrams, examples, practical activities, MCQs and answer explanations.

1. **Introduction to Computers / कंप्यूटर का परिचय** — Definition, characteristics, history, generations, types and applications.
2. **Computer Hardware / कंप्यूटर हार्डवेयर** — CPU, motherboard, RAM, ROM, HDD, SSD, GPU, monitor, keyboard, mouse, ports and power supply.
3. **Input, Output and Storage Devices / इनपुट, आउटपुट और स्टोरेज डिवाइस** — Keyboard, mouse, scanner, microphone, webcam, monitor, printer, speakers, USB drives and memory cards.
4. **Operating System and Windows Basics / ऑपरेटिंग सिस्टम और Windows** — OS concepts, desktop, Start Menu, taskbar, settings, files, folders, app installation and accessibility.
5. **Office Productivity / ऑफिस प्रोडक्टिविटी** — Word processing, document formatting, spreadsheets, cells, formulas, charts, presentations and PDF.
6. **Internet and Networking / इंटरनेट और नेटवर्किंग** — Internet, WWW, browsers, search engines, email, LAN, WAN, router, modem, Wi-Fi and IP address.
7. **Software and Coding Basics / सॉफ्टवेयर और कोडिंग** — System/application software, algorithms, variables, programming logic, HTML, CSS and JavaScript introduction.
8. **Cyber Security and Online Safety / साइबर सुरक्षा** — Strong passwords, MFA, viruses, malware, phishing, privacy, backups, safe downloads and updates.
9. **Keyboard Shortcuts and Typing / कीबोर्ड शॉर्टकट और टाइपिंग** — Keyboard layout, modifier/navigation/function keys, Windows shortcuts, typing posture, home row and accuracy.
10. **Computer Data and Storage Units / कंप्यूटर डेटा और स्टोरेज यूनिट** — Bit, byte, binary, KB, MB, GB, TB, decimal/binary conventions, file extensions and backup.
11. **Basic Troubleshooting / कंप्यूटर की सामान्य समस्याएँ** — Slow computer, internet, printer, audio, app errors, updates and when to seek expert help.
12. **Modern Technology / आधुनिक तकनीक** — AI, cloud computing, blockchain, digital payments, IoT, automation and future skills.

## Lesson quality standard
- Simple, accurate Hindi and English.
- Explain technical terms with everyday examples.
- Use original diagrams or assets with verified licences and attribution.
- Add safe practical tasks that do not require paid software.
- Include 5–10 MCQs per completed lesson, with explanations.
- Review facts and screenshots when software versions change.
