# Computer Siksha Architecture

## Product goals
- Teach computer fundamentals from absolute beginner level.
- Release the complete first version in English and Hindi.
- Work on mobile phones, tablets and desktop browsers.
- Provide offline access to core learning material.
- Keep learning free and privacy-friendly.

## Initial architecture
- Web: HTML5, CSS3 and vanilla JavaScript.
- PWA: Web App Manifest and Service Worker cache.
- Android: Kotlin and Jetpack Compose.
- Shared content: bilingual course data (English + Hindi).
- Local progress: browser local storage initially; Android local persistence.
- Hosting: GitHub Pages for the web client.

## Content model
Each of 12 modules has three lessons. A complete lesson includes:
1. Learning objectives
2. English explanation
3. Hindi explanation
4. Definitions and everyday examples
5. Original/appropriately licensed labelled diagrams
6. Safe practical activity
7. Quiz questions with correct answers and explanations
8. Sources and image attribution where needed

## Release phases
- Phase 1: complete English/Hindi course catalogue, responsive web/PWA and Android app.
- Phase 2: verify all 36 lessons and 24 quizzes in both languages; validate answers and explanations.
- Phase 3: connect Android to the same bilingual offline course data and complete device QA.
- Phase 4: accessibility, performance, backup/export and release checks.
- Later language phase: add the remaining 10 languages only after the English/Hindi release is stable.

## Privacy and safety
No login, wallet connection, payment or collection of personal information is required for basic learning.
