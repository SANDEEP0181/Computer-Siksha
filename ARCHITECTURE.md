# Computer Siksha Architecture

## Product goals
- Teach computer fundamentals from absolute beginner level.
- Support Hindi and English.
- Work on mobile phones, tablets and desktop browsers.
- Provide offline access to core learning material.
- Keep learning free and privacy-friendly.

## Initial architecture
- Web: HTML5, CSS3 and vanilla JavaScript.
- PWA: Web App Manifest and Service Worker cache.
- Android: Kotlin and Jetpack Compose.
- Shared content: bilingual JSON catalogue.
- Local progress: browser local storage initially; Room database in Android.
- Hosting: GitHub Pages for the web client.

## Content model
A course contains modules. Each module contains topics. A full lesson should include:
1. Learning objectives
2. Hindi explanation
3. English explanation
4. Definitions and examples
5. Original/appropriately licensed images and labelled diagrams
6. Practical activity
7. MCQ quiz with explanations
8. Sources and image attribution

## Phases
- Phase 1: project foundation, 12-module catalogue, responsive web/PWA shell and Android shell.
- Phase 2: complete first 100 lessons with diagrams and bilingual content.
- Phase 3: quizzes, bookmarks, search and learning progress.
- Phase 4: offline downloads, certificates and accessibility improvements.
- Phase 5: device testing, security review and public release.

## Privacy and safety
No login, wallet connection, payment or collection of personal information is required for basic learning.
